================================================================================
                             WHAT IT DOES
================================================================================

The test suite automates the complete resume generation workflow:

1. ✅ CREATES TEST USERS
   - Auto-generates unique credentials with timestamps
   - Email: testuser{n}_{timestamp}@testdomain.com
   - Password: TestPassword123!

2. ✅ REGISTERS & AUTHENTICATES
   - POST /user/register - Creates new user accounts
   - POST /auth/login - Authenticates and gets JWT token

3. ✅ CREATES PROFILE
   - POST /profile/ - Creates user profile with details
   - Includes full name, headline, summary, links

4. ✅ ADDS EXPERIENCES
   - POST /experience/ - Adds work experience data
   - Creates multiple experiences per user
   - Includes company, role, dates, tech stack

5. ✅ GENERATES RESUMES
   - POST /content/{jobId} - Generates resume text
   - Tests AI-powered resume generation
   - Returns resume text for verification

6. ✅ REPORTS RESULTS
   - Detailed success/failure counts
   - Error messages for debugging
   - Summary statistics

Fix: Script auto-generates unique emails; try running again

Fix: Install: pip install requests

Fix: Kill process or use different port
